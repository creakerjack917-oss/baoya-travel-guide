## Variant: Trip.com 攻略版

### Design stance
参考 Trip.com 目的地攻略的信息结构：宽幅目的地首图、顶部导航、快捷入口、日期标签、内容卡片和交通分区。

### Key choices
- Layout: 目的地 Hero + 快捷入口 + 按日期切换的一体化时间线，每个时间点右侧配图，另附交通与预约说明。
- Current presentation: 按用户标注收窄为首图 + 日期标签 + 时间线图片卡，移除顶部导航、面包屑、快捷入口、附加说明和页脚。
- Typography: 清晰的无衬线层级，适合手机快速扫描。
- Color: 白底、Trip.com 风格橙色强调、淡橙/淡蓝状态背景。
- Interaction: 日期标签切换每日计划，快捷入口滚动定位并显示反馈。
- Images: 使用参考页面公开展示的苏州目的地图片，并混合平江路、园林实景素材，后续可替换。
- User-provided images: 渔郎桥浜 1 号楼 201 室、熙茉锦婳写真馆已使用用户提供的两张照片，分别对应两张卡片。
- Transport updates: 浦东机场、去程高铁、返程高铁和春秋航空 9C8929 均使用了不同的交通图片，并写入推荐车次与备选车次。

### Trade-offs
- Strong at: 信息密度、导航感、目的地攻略氛围和移动端执行。
- Weak at: 个性化叙事与杂志感弱于 C-1。

### Best for
- 想要类似旅行平台攻略页的正式行程书，方便同行者查看和临场切换。

### Sharing
- 这是纯静态 HTML，不需要数据库或后端。
- 本机预览地址只在当前电脑有效；要发给别人看，需要部署到 GitHub Pages、Netlify 或 Cloudflare Pages 等静态托管服务。
- 这些服务都有免费方案，部署后会得到一个可公开访问的 HTTPS 链接，点击、日期切换和页面内导航都能保留。
- 如果不想部署，也可以用浏览器“打印为 PDF”，适合微信或邮件发送，但 PDF 不保留日期切换等交互。
